# Stockfolio - Frontend

React frontend for the Stockfolio stock portfolio tracker.

## Live Demo
https://stockfolio-woad.vercel.app

## Tech Stack
- React, Vite, Tailwind CSS, Chart.js

## Setup
1. npm install
2. npm run dev
3. Open http://localhost:5173

## Features
- Login and Signup pages
- Dashboard with stock table showing live prices and profit/loss
- Symbol search with autocomplete
- Pie chart showing portfolio distribution
- Add and delete stock holdings
